# TicTacToe 구조 메모

## 파일 구조

- Program.cs
  - 프로그램 시작
  - 게임 실행

- Source.cs
  - Board 클래스
  - Game 클래스

## Board 클래스

- 3×3 보드 관리
- 빈칸은 . 으로 표시
- 위치 번호 출력
- 현재 보드 출력
- 가로, 세로, 대각선 승리 확인
- 빈칸이 없으면 무승부 확인

## Game 클래스

- 현재 보드 생성 (Game() 생성자에 넣어둠)
- X부터 시작
- 입력 처리
- 잘못된 입력이면 다시 입력
- 정상 입력일 때만 보드 변경
- 승리,무승부 확인
- X와 O 차례 변경

## 로직 흐름

게임 시작\
-> 보드 출력\
-> 현재 플레이어 입력\
-> 입력 확인\
-> 보드에 표시\
-> 승리 확인\
-> 무승부 확인\
-> 차례 변경\
-> 반복
